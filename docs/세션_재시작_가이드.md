# 세션 재시작 가이드 — CustomInterpreter (CodeFab)

**작성일**: 2026-06-05  
**목적**: 다른 PC 또는 새 세션에서 동일한 컨텍스트로 작업을 재개하기 위한 완전한 가이드  
**중요**: 이 문서는 **저장소 루트 경로가 달라도** 동작할 수 있도록 작성되었습니다.

---

## 1. 전제 조건

| 항목 | 요구 사항 |
|------|-----------|
| OS | Windows 10/11 (x64) |
| 컴파일러 | Visual Studio Build Tools 2022 이상 (`cl.exe`, MSVC 19.x) |
| CMake | 3.20 이상 |
| PowerShell | 5.1 이상 (빌드 스크립트용) |
| Claude Code | 최신 버전 CLI 또는 Desktop App |

---

## 2. 저장소 설정

```powershell
# 1. 클론 (경로는 원하는 위치로 변경 가능)
git clone <repo-url> CustomInterpreter
cd CustomInterpreter

# 2. 빌드
powershell -ExecutionPolicy Bypass -File build.ps1

# 3. 빌드 확인
out\interpreter.exe tests\test1_expressions.fab
# 기대 출력: 5, 3, 6, -2, 2, true, false, Hello World
```

> **경로 독립성**: `build.ps1`은 스크립트 자신의 위치를 기준으로 동작하므로 어느 경로에 클론해도 무방합니다.

## 3. Claude Code 메모리 설정 (새 PC)

Claude Code는 프로젝트별 메모리를 `%USERPROFILE%\.claude\projects\<경로-인코딩>\memory\` 에 저장합니다.  
새 PC에서는 아래 내용으로 메모리 파일을 직접 생성하거나, **Claude에게 이 문서를 읽힌 뒤 메모리 재구성을 요청**하면 됩니다.

### 메모리 재구성 프롬프트 (Claude에게 붙여넣기)

```

이 프로젝트의 메모리 파일들을 재구성해줘.
```

### 4-2. 구현된 기능 전체 목록

**기본 (Ch.1 — 초기)**
- 숫자/문자열/bool/nil 리터럴
- 산술 연산 (`+`, `-`, `*`, `/`), 비교 연산, 단항 `-`
- 문자열 연결 (`"a" + "b"`)
- `print` 문, `var` 선언, 변수 대입
- 블록(`{}`), `if/else`, `for` 루프
- 정적 검사: 자기 초기화 참조, 동일 스코프 중복 선언

**Ch.2 — 함수**
- `Func name(params) { body }` 선언
- 함수 호출 및 인수 전달
- `return` 값 반환 (중첩 블록 포함)
- `return` 없는 함수 → `nil` 반환
- 재귀 호출
- 클로저 (Lexical Scoping)
- 정적 검사: 함수 외부 `return`, 중복 파라미터

**Ch.3 — 정적 배열**
- `Array(n)` — n개짜리 nil 초기화 배열 생성
- `arr[i] = value` 인덱스 쓰기
- `arr[i]` 인덱스 읽기
- 표현식 인덱스 (`arr[i - 1]`)
- 런타임 검사: 범위 초과, 비숫자 인덱스, 비배열 대상, 비숫자 크기

## 8. 핵심 설계 결정 요약 (빠른 참조)

| 결정 | 이유 |
|------|------|
| `return`에 C++ 예외(`ReturnSignal`) 사용 | 중첩 블록을 자연스럽게 탈출, 기존 `catch(...)` 패턴과 일관성 |
| `FabFunction::body`를 비소유 포인터로 | `FuncStmt`가 AST를 소유, `interpret()` 수명 동안 안전 |
| `FabFunction` / `FabArray` forward declaration in `Token.h` | `Value` variant에 포함 필요 + 순환 의존성 방지 |
| `Array()`를 `ARRAY_KW` + `ArrayCreateExpr`로 처리 | 내장 함수 대비 Resolver/Interpreter 타입 검사가 명확 |
| `IndexSetExpr`를 `assignment()`에서 `IndexGetExpr` 재변환으로 생성 | `arr[i] = v` 구문이 대입 표현식 형태이기 때문 |
| 클로저: `fn->closure = currentEnv` (선언 시점 캡처) | Lexical Scoping — 호출 위치가 아닌 선언 위치의 환경 참조 |
