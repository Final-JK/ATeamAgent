## 1. 빌드 방법


## 4. Chapter 2 — 함수 기능 테스트 상세

### test4_functions.fab 기대 출력

```
10
120
Hello World
nil
```

### 테스트 항목

| 항목 | 코드 예시 | 기대 결과 |
|------|-----------|-----------|
| 기본 함수 선언/호출 | `Func add(a, b) { return a + b; }` | 정상 실행 |
| 반환값 대입 | `var ret = add(3, 7);` | `ret == 10` |
| 재귀 호출 | `fact(5)` | `120` |
| 문자열 파라미터 | `greet("World")` | `Hello World` |
| return 없는 함수 | `noReturn()` | `nil` 반환 |

## 5. Chapter 3 — 배열 기능 테스트 상세

### test5_arrays.fab 기대 출력

```

30
7
```

### 테스트 항목

| 항목 | 코드 예시 | 기대 결과 |
|------|-----------|-----------|
| 배열 생성 | `var arr = Array(3);` | nil 3개짜리 배열 |
| 인덱스 쓰기 | `arr[0] = 10;` | 정상 대입 |
| 인덱스 읽기 | `print arr[0];` | `10` 출력 |
| 표현식 인덱스 | `arr[i - 1] = 7;` | 정상 대입 |
